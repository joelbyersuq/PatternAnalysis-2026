# Failed runs and what went wrong

Running log of failed or surprising runs. Source material for the README's failure
autopsies, so record the evidence (numbers, case IDs, slice indices) while it is fresh.

Template for each entry:

```
## YYYY-MM-DD — short title
- Run: command / Slurm job ID, model, key settings
- What happened: symptom (loss curve, Dice per class, crash message)
- Cause: what it turned out to be (or best guess)
- Fix / next step:
- Cases affected: case IDs, slice ranges (base/apex?)
```
